# 多米的牛津树学习资料

存放孩子学习牛津树（Oxford Reading Tree）的音频及配套资料，逐步探索与家中设备的配合方式，包括寻听机、小爱同学，以及家用硬件的逆向研究和改造。

## 目录

- `materials/`：原始音频、书目及配套资料。建议按级别、书名整理，例如 `materials/level-01/书名/`。
- `devices/`：设备型号、连接方式、兼容格式、操作步骤和研究记录。
- `output/`：转换、重命名或整理后，准备导入设备的文件。
- `AGENTS.md`：编码助手在本项目中的工作约定。

原始资料保留不动，加工结果放入 `output/`。实际音频、学习资料和导出文件默认不纳入 Git；项目说明和设备研究记录可以纳入版本管理。Git 不代替资料备份。

目前只建立目录和约定。收到具体设备型号和需求后，再确定导入或改造方案，不预设设备支持的协议、格式或接口。
